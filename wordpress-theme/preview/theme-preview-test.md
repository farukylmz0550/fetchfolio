# Theme Preview: Editing a WordPress Post

This is a separate development-only post. It checks that a WordPress post can be created and edited from the admin dashboard while keeping the terminal look.

## Formatting check

The post template should display headings, paragraphs, lists, inline **bold text**, links, code, and quotations.

- Create a post in **Posts → Add New**.
- Set its title, excerpt, and date.
- Publish it, then open the Blog page to see the result.

```text
wp-admin → Posts → Add New
```

> This sample belongs to the development preview and can be replaced from WordPress Admin.
