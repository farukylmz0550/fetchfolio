# FetchFolio WordPress Theme

FetchFolio is a terminal-inspired portfolio theme for WordPress.

## Install

Download the WordPress theme ZIP from the Releases page. In WordPress, open
**Appearance → Themes → Add New → Upload Theme**, choose the ZIP, then install
and activate **FetchFolio**. To install manually, copy `wordpress-theme/fetchfolio`
to `wp-content/themes/fetchfolio`.

On first activation, FetchFolio creates editable placeholder pages and two
placeholder blog posts. Update them in **Pages** and **Posts**. The homepage
sections, terminal identity, links, and ASCII art are configurable in the
WordPress dashboard. The theme includes light and dark modes, with dark mode as
the default, and remembers a visitor's privacy choice.

Published pages and posts have a Markdown companion at the same URL with
`.md` appended. Blog posts use `/blogs/<post-slug>` URLs. Search engine crawlers
are allowed to index public content; `robots.txt` and `/ai.txt` describe the
theme's crawler policy. WordPress protects dashboard access with its normal
login and capability checks.
