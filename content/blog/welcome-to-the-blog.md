# Welcome to the FetchFolio blog

FetchFolio now has a small, file-based blog for development notes, guides and
project updates.

## How it works

Each post is a Markdown file under `content/blog/`. The `index.json` file is
the catalogue used by the blog index, so adding a post only requires a new
Markdown file and one catalogue entry.

This keeps the site fast, portable and easy to edit: there is no database,
build pipeline or admin panel to maintain.

> New posts can be published by committing the Markdown file and its catalogue
> entry.
